# 东莞理工学院优学院助手

本项目是统一后的最新版，仅保留 **Python 本地服务 + React 浏览器前端**。它用于课程读取、签到活动监测和课件学习辅助，不再包含旧 Tkinter/PyQt 原型、Tauri 桌面壳或历史发布包。

## 启动

Windows 下双击 `启动浏览器版.bat`。启动器会按需安装前端依赖、启动仅监听 `127.0.0.1` 的本地服务，并以 Chromium 调试模式打开网页前端。

关闭前端标签页后，本地服务会自动退出；也可在网页命令框或启动器终端输入 `kill`。
