# 东莞理工学院优学院助手

本项目是统一后的最新版，仅保留 **Python 本地服务 + React 浏览器前端**。它用于课程读取、签到活动监测和课件学习辅助，不再包含旧 Tkinter/PyQt 原型、Tauri 桌面壳或历史发布包。

## 启动

Windows 下双击 `启动浏览器版.bat`。启动器先确认浏览器，再启动仅监听 `127.0.0.1` 的后台服务和网页前端，最后以 Chromium 调试模式打开程序；网页打开成功后，启动终端会自动关闭，服务继续在后台运行。

浏览器按已保存路径、Edge、Chrome、其他 Chromium 的顺序查找；常见路径均无效时，终端会持续引导用户填写 `msedge.exe` 或 `chrome.exe` 的完整地址，含空格的地址可使用英文双引号。

终端只负责启动和在首次找不到浏览器时引导填写程序路径，其他配置统一在网页端“设置”中完成。终端显示优先使用 UTF-8，不支持时自动回退到 GBK；该回退只影响终端输入输出，配置、缓存、日志和网页通信始终使用 UTF-8。关闭网页标签后，独立后台服务会自行退出并清理子进程。

刷课前请在该调试浏览器中打开具体课件学习页（URL 含 `ua.dgut.edu.cn/learnCourse`）。启动后会先回到课程第一张可见页面，再按真实页面状态处理视频、文档和测验；课件标签页可留在后台，脚本不会主动切换到该标签页。

## 应用内自动更新

程序内置类似 MaaAssistantArknights 的自动更新：

1. 后台服务启动数秒后自动检查 GitHub Release（也可在“关于”页手动检查）。
2. 发现新版本后自动在后台下载完整 ZIP（支持断点续传、最多 3 次自动重试），下载期间签到监测与刷课不受影响；前端右上角显示轻量进度 Toast 与消息按钮未读徽标。
3. 下载完成并通过 SHA-256 校验后，右上角消息抽屉中等待确认；点击“暂不更新”可继续使用当前版本，下次启动仍可安装。
4. 点击“立即更新”后：前端尝试 `window.close()` → 后端通过 CDP 只精确关闭助手自己的标签页（不影响优学院页面和整个浏览器）→ 停止签到/刷课/本地服务 → 临时目录中的独立更新器取得 `Local\YxyAssistant.Updating` 互斥锁 → 备份并替换文件 → 自动重启新版本。
5. 安装失败会自动回滚到旧版本并重启；首次启动弹出一次性对话框，之后只保留在消息抽屉中。
6. 更新期间重复启动程序会被 `Local\YxyAssistant.App` / `Updating` 命名互斥锁拦截并提示等待。

`config.json`、`auth.json`、`account.json`、`browser_profile/`、`签到记录.md`、运行日志等用户数据在更新时永不覆盖；更新状态持久化在 `.update/state.json`，页面刷新或重启后都能恢复真实进度。

## 发布新版本

1. 修改 `version.py` 中的 `APP_VERSION` 和 `web/package.json` 的 `version`（保持一致）。
2. 提交并推送 tag（如 `v0.3.0`），GitHub Actions 会自动构建前端、生成包含 `version/url/size/sha256/changelog` 的 `manifest.json` 与完整 ZIP，并上传到 Release。
3. 用户端程序读取 Release 中的 `manifest.json` 完成后续自动更新；发布包内含 `web/dist` 构建产物，用户无需 `npm install`。
